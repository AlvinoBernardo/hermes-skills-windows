# Editor brain (original mode): pointer + core rules

Full synthesis: `~/IkkimiAssets/research/editor-brain/EDITOR-BRAIN.md` (R1-R8 reports in the same folder: editors' tutorials, effects/text vocab, 21 recent viral edits measured, Alvino's feedback, @carlsunraku, @fireflo_edits, @lucasmikaze + @tentamv_). Read it before any original-mode edit.

Core rules:
- Top editors keep a FIXED signature look and vary anime x song x concept x one gimmick per post. Originality = a new concept card, not new effects.
- Write a concept card first (anime in its hype window, song = 3+ recent edits or an English sing-along chorus, idea type = lyric-video / hook-word / story-with-turn / pulse-and-hold, one new gimmick) and get his OK in 2 lines.
- Difference check: differ from any known edit on >=3 of concept, song version, cast, type system, gimmick.
- Grammar is per idea type (table in EDITOR-BRAIN §2): lyric edits cut on vocal onsets (2-3.5 shots/s); hype cuts on kicks/impacts with a ~1.5x step at the drop, ~2 f flashes, 4 f zoom pulses, 0.17 s shakes; sad edits beat-lock and accelerate.
- Effects never carry the edit: rough-cut with hard cuts only, swap clips if it doesn't flow.
- Ship 3-5 variants per concept (about 1 in 4-5 hits), master -8 to -10 LUFS.
- Data on what works expires: refresh the editor reports from posts of the last ~2 months (views/day), not all-time hits.
