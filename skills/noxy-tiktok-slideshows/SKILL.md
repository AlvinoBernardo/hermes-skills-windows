## On Windows (this PC)
- **Project root:** `~/Desktop/Noxy` on the Mac is `C:/Users/<you>/Desktop/Noxy` here. Every `~/...` path in this skill or its references is a Mac path: replace `~` with `C:/Users/<you>`, or better `Path.home()`. The Mac's Noxy library (photo library, Finished-slides, References, rotation JSONs, approved assets, `_source` kits) is NOT on this PC yet. Create `Desktop/Noxy` on first use, and ask the user to copy the folder from the Mac before any step that needs history, hashes or approved assets. Say so plainly instead of guessing.
- **Python:** `tt_post_fetch.py` and `tt_music_fetch.py` are stdlib-only (plain `python` works; they now read/write UTF-8, which Windows needs for emoji hooks). Anything with PIL/numpy/scipy/cv2/rembg (render kits, `package_delivery.py`, dHash audits) runs on the engine venv `C:/Users/<you>/IkkimiAssets/engine/.venv/Scripts/python.exe`. That replaces `env -u PYTHONPATH -u PYTHONHOME /usr/bin/python3`. Run it from `terminal`, not `execute_code`. There is no `imagehash`: use the `bin(a ^ b).count('1')` dHash already described below. Delivery root is `$NOXY_ROOT` or `~/Desktop/Noxy`.
- **Fonts** (Apple fonts are absent; `IkkimiAssets/engine/portable.py resolve_font(path, index)` already maps Mac font paths): Arial Black = `C:/Windows/Fonts/ariblk.ttf`, Arial Bold = `arialbd.ttf` (same family, same look). Avenir Next Condensed = `bahnschrift.ttf` or `engine/fonts/Antonio[wght].ttf`; Avenir Next Medium = `engine/fonts/Montserrat[wght].ttf`. TikTok Sans is not installed: Montserrat or Poppins from `engine/fonts`. Apple Color Emoji = `seguiemj.ttf` with `draw.text(..., embedded_color=True)` (verified colour output; PIL here has no raqm). Glyph metrics differ, so refit sizes against measured outline bounds in code; the Mac-fitted numbers (e.g. the 93px Arial Black hook) are starting points, not guarantees.
- **Apple Vision cutouts** (`vnmask.swift`, `swiftc`) don't exist: use `rembg` in the engine venv (`from rembg import remove`; CUDA via `engine/portable.py onnx_providers()`) as the primary alpha, then keep the flood-fill add-back, 2px erode and mid-grey QC below. Untested on Noxy product photos.
- **Tools:** `whisper-cli` is `C:/Users/<you>/tools/whisper/Release/whisper-cli.exe` (16 kHz mono s16 wav only); the large-v3-turbo model at `~/.cache/openwhispr/whisper-models/` exists here too. `yt-dlp` is `~/.local/bin/yt-dlp.exe`, node is installed for `--js-runtimes node`. Playwright lives in `~/.hermes/tools/social-scraper/.venv`. Image generation needs the Codex login: see `codex-image-generation`.
- **Delivery:** "open in Finder" = `explorer.exe "C:/Users/<you>\Desktop\Noxy\<folder>"` (backslashes) or just print the path. MEDIA paths: `C:/Users/<you>/...` forward slashes, no whitespace anywhere. Windows Python writes `\r\n`: keep `newline='\n'` for files that Mac tools or bash loops will read.
