## Generation workflow
- Load image and codex-image-generation. Use the normal image_generate tool with the configured backend; no backend change is necessary when openai-codex is already selected.
- Generate three separate full-body poses on one 1536x1024 landscape asset sheet. Ask for pure white background, equal vertical thirds, clear white gutters, full feet/heads and all props contained inside each third, no text. Reference the accepted first sheet in later image requests for consistency.
- Inspect every returned sheet. A detailed request for white can still yield a dark backdrop. Correct that with an image edit before compositing; don't force dark-background art into a light poster. The successful correction explicitly requested featureless #FFFFFF, flat colours, less realism and complete margins.
- Check actual figure boundaries instead of blindly cutting into exact thirds. Beds, counters, dumbbells and hands may cross the requested gutters. Use visually checked per-sheet cut positions and tight ink bounds; regenerate if a prop is truly clipped at the sheet edge.
- Retain original sheets, source paths, model/provider receipts, request IDs and hashes. Use white-background multiplication onto subtle cream paper to integrate line art without deleting white clothing or erasing fine hatching.
- Add headlines, labels, body copy, icons and real app card in a deterministic renderer after generation. This prevents misspellings and inconsistent slide typography. Use the approved Avenir Next Condensed Heavy / Condensed Bold / Avenir Next Medium pairing described above. DIN Condensed Bold and Arial were the superseded first-draft pairing. Avoid overcomplicating the slides with heavy labels or card chrome.
- Font metrics and actual line wrapping must drive layout. Reserve room under app copy for the real listing; a longer paragraph can otherwise collide with the bottom takeaway. Assert bounds for both aspect ratios and inspect all final slides.
- Deliver one inline contact-sheet preview per slideshow plus a combined ZIP before the previews. Each individual ZIP should be adjacent to its preview. Include numbered full-resolution images and captions. Keep all MEDIA paths whitespace-free.
